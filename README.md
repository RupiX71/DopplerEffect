# Doppler Effect Visualization

A real-time visualization of the Doppler effect built with C++ and SFML.
The sound waves expand dynamically following the mouse cursor.

## How to run
Requires SFML installed on your system. Compile with:
g++ main.cpp -o doppler -lsfml-graphics -lsfml-window -lsfml-system
./doppler
